# U Hrocha – Android aplikace (soubory ke stažení)

Tady jsou jen hotové soubory **APK** soukromé aplikace „U Hrocha“ (evidence setkání party).
Zdrojový kód tu není.

- Nejnovější verze: **Releases → Latest** → soubor `u-hrocha-X.Y.Z.apk`.
- Aplikace se po instalaci aktualizuje sama (karta „Je nová verze“ na Domů).
- Přihlásit se dá jen pozvaným účtem Google – bez pozvánky aplikace nic neukáže.
- Soubory jsou podepsané vždy stejným klíčem; Android jinak aktualizaci nedovolí.
